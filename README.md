# APUS-commands
The commands to install packages from APUS (Altus Project User Software).

This is going to be the "main" way to install user software in Altus so... good!

# HOW TO INSTALL:

On your terminal type:
git clone https://github.com/Altus-Project-Community/APUS-commands.git

cd APUS-commands

then do:
sudo chmod +x install.sh

sudo ./install.sh

Enjoy having APUS in your system!
